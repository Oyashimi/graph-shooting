# 数学グラフバトル！ 📐🎯

数学の関数 `y = f(x)` を入力し、そのグラフを**弾道**にして的を撃ち抜くシューティングゲーム。

- 自分（砲台）は平面の原点 (0,0) に置かれる（＝関数の原点）
- 入力した関数のグラフが、原点から**左右両方向へ伸びる曲線**になる
- 平面に出現する**的を曲線が貫けばヒット**。全部貫けばステージクリア！
- ステージが進むと的が増え、1本の曲線で複数を貫く数学パズルに

> ※ 砲台のランダム配置・向きの回転は今後の拡張予定。現状は原点固定・回転なし。

## 遊び方

```bash
# このフォルダで簡易サーバを起動
python3 -m http.server 8765
```

ブラウザで <http://localhost:8765/> を開く。
（関数評価に mathjs を CDN から読み込むため、初回はネット接続が必要）

下の入力欄に関数を入れて「発射 🔥」。入力例：

| 入力       | 説明           |
| ---------- | -------------- |
| `x^2`      | 放物線         |
| `2*x + 1`  | 直線（傾き・切片で狙う） |
| `sin(x)`   | 波             |
| `3/x`      | 双曲線         |
| `0.5*x^2 - 3` | 平行移動した放物線 |

砲台の向きと関数の形を組み合わせて、的に軌道を重ねよう。
発射前は薄く軌道プレビューが出るので、調整してから撃てる。

## 構成

| ファイル      | 役割                                  |
| ------------- | ------------------------------------- |
| `index.html`  | 画面のレイアウト                      |
